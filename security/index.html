هذه الصفحة تعرض الضوابط المطبقة فعلياً في NEXORA بدون ادعاءات أو شارات غير موثقة.

الوصول والصلاحيات

  • تسجيل دخول عبر Supabase Auth.
  • أدوار Owner / Admin / Manager / Sales / Developer.
  • الوصول الإداري مقيّد بالحسابات المعتمدة والفعالة.

عزل بيانات العملاء

  • بوابة عميل مستقلة.
  • RLS على البيانات الحساسة.
  • المستخدم يرى البيانات المسموح بها لحسابه فقط.

الموافقات البشرية

  • الإرسال الخارجي والصرف والنشر الحساس يبقى خلف Approval Center.
  • Autopilot يجهز مسودات وخطط ولا يتجاوز بوابة الموافقة.

المراقبة

  • System Health وError Center داخل لوحة الإدارة.
  • تسجيل نشاط إداري للأحداث المدعومة.
  • فحوص GitHub Pages تمنع نشر مسارات مكسورة.
