# NEXORA AI

NEXORA AI is the production Next.js application for the public website, NEXORA Command, and the Client Portal.

## Stack
- Next.js 15 / React 19 / TypeScript
- Tailwind CSS
- Supabase Auth, Database, Storage, and Edge Functions
- GitHub Pages static export

## Production routes
- `/` Arabic public website
- `/en/` English public website
- `/login/` Owner / staff access
- `/command/` internal operations dashboard
- `/portal/` client portal
- `/security/` security overview
- `/status/` public route status
- `/insights/` NEXORA insights

The repository intentionally contains one production frontend architecture only: `app/`, `components/`, `lib/`, `public/`, and supporting configuration/migrations.
